3 Fitur Offline-First dan Batasannya

Fitur transaksi utama dirancang offline-first dan data operasional utama disimpan secara lokal di perangkat. Penjualan, pemindaian barcode, cetak struk, buku kas, dan laporan tetap berjalan penuh tanpa koneksi internet.

Aktivasi/validasi lisensi, fitur online tertentu, dan backup yang tersedia membutuhkan koneksi internet:

  • Aktivasi lisensi — saat pertama kali Anda memasukkan kode lisensi dan email pemilik.
  • Validasi lisensi manual — hanya saat Anda menekan tombol verifikasi di menu Pengaturan.
  • Backup manual ke Google Sheets — saat Anda menekan “Cadangkan Sekarang”.
  • Pelacakan penggunaan terbatas — kami mencatat peristiwa pembuka aplikasi secara terbatas untuk keperluan statistik.

Buku Warung tidak melakukan validasi lisensi berkala secara otomatis di latar belakang. Setelah aktivasi berhasil, aplikasi tetap berjalan offline tanpa memerlukan koneksi internet.

4 Data yang Disimpan di Perangkat Anda

Berikut data yang disimpan di penyimpanan internal aplikasi pada perangkat Anda. Data ini berada di bawah kendali Anda dan tidak dikirim ke server kami.

4.1 Data operasional usaha

  • Produk dan kategori: nama barang, barcode, harga beli, harga jual, stok, stok minimum, satuan, dan status pajak.
  • Transaksi penjualan: nomor transaksi, tanggal, total, subtotal, diskon, pajak, metode pembayaran, dan rincian item.
  • Pembelian dan kulakan: nomor transaksi, tanggal, total, metode pembayaran, dan rincian item.
  • Stok: mutasi stok masuk dan keluar beserta catatan.
  • Laporan: laporan penjualan, pembelian, laba rugi, arus kas, dan piutang yang dibuat dari data di atas.

4.2 Data keuangan

  • Buku kas: catatan pemasukan dan pengeluaran harian.
  • Hutang dan piutang: catatan utang pelanggan beserta riwayat pembayaran cicilan.
  • Hutang supplier: catatan utang belanja ke supplier beserta status pelunasan.
  • Retur penjualan dan pengembalian dana.

4.3 Data gambar

  • Foto produk — disimpan sebagai berkas gambar di penyimpanan internal aplikasi.
  • Foto QRIS merchant — disimpan sebagai berkas gambar di penyimpanan internal aplikasi.

Berkas gambar tersebut tidak diunggah otomatis ke server mana pun. Mereka hanya keluar dari aplikasi jika Anda sendiri mengekspornya atau membagikannya.

4.4 Profil usaha & preferensi

  • Profil usaha: nama usaha, nama pemilik, nomor telepon, alamat, dan jenis usaha.
  • Preferensi tampilan, format struk, dan pengaturan printer.
  • Pengaturan pajak (PPN) bila diaktifkan.
  • Data lokal terkait lisensi: email pemilik, status lisensi, dan ID perangkat (UUID).
  • Status penandaan notifikasi yang sudah dibaca di dalam aplikasi.

4.5 Data keamanan lokal

  • Status apakah PIN diaktifkan, serta hash PIN dengan salt (nilai salt dan hash-nya). Aplikasi menyimpan hash, bukan PIN itu sendiri.
  • Kode lisensi disimpan terenkripsi di penyimpanan internal aplikasi dengan keystore sistem Android.

5 Data Pelanggan dan Supplier

Penting: Buku Warung dapat digunakan untuk mencatat data pribadi orang lain, yaitu pelanggan dan supplier Anda. Data tersebut adalah data pribadi mereka, dan Anda adalah pengendali data tersebut. SKMNetwork tidak menerima dan tidak memproses isi data pelanggan maupun supplier Anda.

Data yang dapat Anda masukkan untuk masing-masing pihak:

  • Pelanggan: nama, nomor telepon, alamat, catatan batas utang, serta riwayat utang dan pembayaran cicilan.
  • Supplier: nama, nomor WhatsApp atau telepon, alamat gudang, serta riwayat utang belanja dan pembayaran.

Seluruh data ini hanya tersimpan di perangkat Anda. Bila Anda memakai fitur backup manual ke Google Sheets, data tersebut ikut disalin ke spreadsheet di akun Google milik Anda sendiri.

Sebagai pengendali data, Anda bertanggung jawab memperoleh persetujuan yang semestinya dari pelanggan dan supplier sebelum memasukkan data mereka, serta atas pemrosesan berikutnya atas data tersebut.

6 Data yang Dikirim ke Server Lisensi SKMNetwork

Buku Warung tidak memiliki sistem akun daring. Namun, untuk memvalidasi lisensi, aplikasi berkomunikasi dengan server lisensi SKMNetwork di https://license.skmnetwork.com melalui koneksi HTTPS terenkripsi.

Data Kapan dikirim

Kode lisensi Saat aktivasi dan saat Anda menekan verifikasi manual
ID perangkat (UUID acak milik aplikasi) Saat aktivasi dan saat Anda menekan verifikasi manual
Alamat IP (otomatis oleh jaringan) Pada setiap permintaan jaringan

6.2 Tentang ID perangkat

ID perangkat yang dikirim adalah UUID acak yang dibuat oleh aplikasi di perangkat Anda. Ini bukan IMEI, nomor seri telepon, ID perangkat keras, atau pengenal perangkat permanen. Nilainya dapat berubah apabila data aplikasi dihapus atau aplikasi dipasang ulang.

Buku Warung tidak mengumpulkan IMEI, IMSI, nomor SIM, nomor seri perangkat, model perangkat, ID iklan, atau alamat MAC.

6.3 Data yang disimpan di server lisensi

Untuk memproses lisensi, pembelian, dan dukungan, server menyimpan nama, nomor WhatsApp, dan email pemesan; kode lisensi; ID perangkat; serta riwayat status lisensi dan aktivasi. Akses ke data ini terbatas pada tim SKMNetwork yang menjalankan operasional lisensi dan dukungan.

7 Data Pemesanan dan Pembayaran

Pemesanan lisensi dilakukan melalui halaman pemesanan resmi SKMNetwork. Data yang diminta:

  • Nama pemilik warung
  • Nomor WhatsApp aktif
  • Email aktivasi pemilik
  • Nomor pesanan, nilai pesanan, metode pembayaran, dan referensi pembayaran

Buku Warung tidak memproses dan tidak pernah menerima nomor kartu kredit atau debit, CVV, PIN kartu, maupun kredensial login bank Anda. Pembayaran dilakukan melalui QRIS atau transfer bank di luar aplikasi, dan pembayaran diverifikasi secara manual oleh tim SKMNetwork.

8 Backup Manual ke Google Sheets (Opsional)

Buku Warung menyediakan fitur backup manual opsional ke Google Spreadsheet. Fitur ini tidak berjalan otomatis. Pencadangan hanya terjadi ketika Anda sendiri menekan tombol “Cadangkan Sekarang” di menu Pengaturan.

8.1 Status implementasi saat ini

Pada versi rilis saat ini (v0.2.1), konfigurasi otorisasi Google yang diperlukan untuk menjalankan proses pencadangan belum diaktifkan. Karena itu, proses pencadangan ke Google Sheets belum dapat diselesaikan pada versi ini.

Fitur ini sedang diselesaikan, termasuk verifikasi OAuth Google yang diwajibkan, sebelum diaktifkan. Fitur ini bersifat opsional dan tidak diperlukan untuk penggunaan aplikasi sehari-hari.

8.2 Ketentuan bila fitur ini diaktifkan

  • Spreadsheet dibuat secara otomatis di Google Drive milik akun Google Anda sendiri. SKMNetwork tidak memiliki akses ke spreadsheet tersebut.
  • Aplikasi meminta izin akses Google Sheets dan Drive dengan cakupan spreadsheets dan drive.file.
  • Data yang disalin mencakup profil usaha, produk dan kategori, data pelanggan (nama, telepon, alamat), data supplier (nama, telepon, alamat), seluruh transaksi penjualan dan pembelian beserta nilainya, buku kas, hutang piutang pelanggan, hutang supplier, mutasi stok, serta catatan bebas yang Anda ketik pada kolom keterangan.
  • Data ditulis sebagai sel spreadsheet biasa tanpa enkripsi tambahan dari aplikasi. Isi spreadsheet dapat dibaca oleh siapa pun yang memiliki akses ke akun Google tersebut.
  • PIN dan kode lisensi tidak pernah disertakan dalam cadangan.
  • Pemulihan (restore) akan menimpa data usaha di perangkat dengan data dari spreadsheet.
  • Tombol “Putuskan” pada aplikasi hanya memutus koneksi lokal. Hal ini bukan penghapusan spreadsheet. Untuk menghapus cadangan, Anda perlu menghapus file spreadsheet di Google Drive secara langsung.

9 Pencadangan Android (Android Auto Backup)

Sistem Android menyediakan fitur pencadangan otomatis aplikasi ke Google Drive. Pada Buku Warung, data aplikasi yang sensitif dikecualikan dari fitur ini agar database usaha, preferensi aplikasi, data PIN, foto produk, foto QRIS, dan kredensial lisensi tidak tersalin ke pencadangan Android tanpa kendali.

Konsekuensinya, Anda tidak dapat mengandalkan Android Auto Backup untuk memulihkan data usaha. Untuk cadangan data usaha, gunakan fitur backup manual yang dijelaskan pada Bagian 8.

Pengaturan pencadangan Android berada di pengaturan sistem perangkat Anda dan berada di luar kendali SKMNetwork.

11 Kamera, Barcode, dan Foto

  • Pemindaian barcode — pemrosesan gambar kamera dilakukan sepenuhnya di perangkat Anda. Frame kamera dari fitur pemindaian barcode tidak diunggah ke server mana pun.
  • Foto produk — foto yang Anda ambil atau pilih disimpan di penyimpanan internal aplikasi dan tidak diunggah otomatis.
  • Foto QRIS merchant — disimpan di penyimpanan internal aplikasi dan tidak diunggah otomatis.

Gambar keluar dari aplikasi hanya jika Anda sendiri memilih mengekspor atau membagikannya, sebagaimana dijelaskan pada Bagian 14.

12 Bluetooth dan Printer Thermal

Izin Bluetooth digunakan untuk komunikasi lokal dengan printer thermal 58 mm atau 80 mm melalui Bluetooth, serta printer yang terhubung melalui kabel USB OTG. Penemuan dan pairing perangkat printer dilakukan di dalam jaringan lokal perangkat Anda dan data tersebut tidak dikirim ke server SKMNetwork.

13 PIN dan Keamanan Akses

  • Buku Warung dapat dikunci dengan PIN pemilik 4 angka untuk mengurangi akses orang lain ke aplikasi saat perangkat berpindah tangan.
  • PIN disimpan sebagai hash PIN dengan salt (SHA-256 dengan salt acak) pada penyimpanan internal aplikasi. Aplikasi menyimpan hash, bukan PIN itu sendiri.
  • Kode lisensi disimpan terenkripsi di penyimpanan internal aplikasi menggunakan keystore sistem Android.
  • PIN hanya berlaku pada satu perangkat. Buku Warung tidak menyediakan pemulihan PIN dan tidak memakai biometri seperti sidik jari atau pengenalan wajah.

PIN adalah lapisan keamanan perangkat, bukan pengganti measures keamanan data yang lain. Bila perangkat hilang atau tidak dikunci dengan benar, data pada perangkat tetap dapat diakses pihak lain.

14 Berbagi Data oleh Anda Sendiri

Buku Warung menyediakan fitur untuk Anda mengirim data ke aplikasi lain. Berbagi ini hanya terjadi atas tindakan Anda sendiri dan berlangsung melalui dialog berbagi sistem Android, sehingga Anda memilih aplikasi tujuan.

  • Katalog produk ke WhatsApp — Anda dapat mengirim daftar produk dan harga ke percakapan WhatsApp.
  • Purchase Order ke WhatsApp — Anda dapat mengirim dokumen pesanan pembelian ke supplier melalui WhatsApp.
  • Laporan PDF — Anda dapat membagikan laporan penjualan, pembelian, laba rugi, arus kas, atau piutang sebagai berkas PDF.
  • Hubungi CS SKMNetwork — tautan WhatsApp menuju tim dukungan.

Berkas PDF laporan disimpan di area cache aplikasi dan dibagikan melalui penyedia konten Android. SKMNetwork tidak menerima laporan tersebut, kecuali Anda mengirimkannya sendiri kepada tim dukungan.

15 Pelacakan pada Situs Web

Situs bukuwarung.skmnetwork.com tidak menggunakan cookie iklan, cookie pelacak pihak ketiga, atau profil pengguna. Situs ini juga tidak memuat formulir yang meminta data pribadi Anda.

Namun, kami mencatat beberapa peristiwa secara terbatas untuk mengukur efektivitas halaman:

  • Peristiwa seperti kunjungan halaman, harga produk dilihat, dan klik tombol.
  • Parameter pemasaran (UTM) jika Anda datang melalui tautan kampanye.
  • Pengenal teknis sementara (lead token) yang bersifat pseudonim untuk menghubungkan kunjungan dengan transaksi pembelian.
  • Hash dari alamat IP dan User-Agent, yang dapat diproses untuk keperluan statistik, keamanan, dan pencegahan penyalahgunaan.

Seluruh peristiwa tersebut dikirim ke server milik SKMNetwork sendiri, bukan ke jaringan iklan pihak ketiga.

Situs ini memuat font dari Google Fonts. Pemuatan font tersebut melakukan permintaan jaringan ke server Google, sehingga Google dapat menerima alamat IP dan User-Agent Anda.

17 Penghapusan Data

17.1 Data di perangkat Anda

  • Menghapus seluruh data aplikasi melalui Pengaturan sistem, Aplikasi, Buku Warung, lalu Hapus Data.
  • Meng uninstall aplikasi dari perangkat.
  • Menghapus backup spreadsheet secara manual di Google Drive Anda.

Perhatian: Buku Warung saat ini belum menyediakan tombol “hapus semua data” di dalam aplikasi. Penghapusan data usaha dilakukan melalui pengaturan sistem perangkat.

17.2 Data di server SKMNetwork

Saat ini belum tersedia fitur penghapusan mandiri atas data pemesanan dan lisensi yang tersimpan di server SKMNetwork.

Jika Anda tidak lagi menggunakan Buku Warung dan ingin meminta penghapusan email, nomor WhatsApp, atau data pemesanan Anda dari server, silakan hubungi kami melalui support@skmnetwork.com beserta email yang Anda gunakan saat pembelian. Permintaan Anda akan diverifikasi dan diproses oleh tim SKMNetwork sesuai ketentuan retensi pada Bagian 16.

Mekanisme penghapusan dan anonimisasi administratif sedang dikembangkan oleh SKMNetwork.

18 Keamanan

  • Komunikasi dengan server lisensi dan pemesanan menggunakan HTTPS.
  • Kode lisensi disimpan terenkripsi pada penyimpanan internal aplikasi menggunakan keystore sistem Android.
  • PIN disimpan sebagai hash PIN dengan salt, bukan sebagai angka PIN itu sendiri.
  • Aplikasi menggunakan sandbox penyimpanan internal Android sehingga data tidak dapat diakses oleh aplikasi lain.

Untuk menjaga data usaha Anda, tetapkan kunci layar pada perangkat Anda dan lindungi perangkat dari akses pihak lain. Aplikasi tidak dapat melindungi data dari orang yang memegang perangkat dalam keadaan terbuka.

19 Usia Minimum

Buku Warung ditujukan untuk pengguna berusia 18 tahun ke atas yang menjalankan usaha. Aplikasi tidak mengumpulkan dengan sengaja data pribadi anak. Dengan menggunakan aplikasi, Anda menyatakan bahwa Anda telah mencapai usia 18 tahun.
